\# Worker Training Project



\## Purpose



This project is a training project created to practice C#, Entity Framework Core, PostgreSQL, ASP.NET Core REST APIs, Next.js, and Git version control.



The project demonstrates how a frontend application communicates with a backend API and how the backend interacts with a PostgreSQL database.



\## Project Structure



\- `WorkerSystemEF` - C# and Entity Framework Core training project.

\- `WorkerApiCore` - ASP.NET Core REST API connected to PostgreSQL.

\- `worker-frontend` - Next.js frontend application.



\## Setup Instructions



1\. Make sure PostgreSQL is running.

2\. Open `WorkerApiCore` in Visual Studio.

3\. Configure the PostgreSQL connection using User Secrets.

4\. Run the ASP.NET Core API.

5\. Open `worker-frontend` in VS Code.

6\. Run the frontend using:



&#x20;  npm.cmd run dev



7\. Open the application in the browser at:



&#x20;  http://localhost:3000



\## Planned Functionality



\- View workers.

\- Add new workers.

\- Edit worker information.

\- Delete workers.

\- Validate worker data.

\- Connect the Next.js frontend to the ASP.NET Core REST API.

\- Store worker data in PostgreSQL.
